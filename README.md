# ollama-multi-chat

Приложение для общения нескольких локальных моделей Ollama между собой с вашим участием.

## Требования

- Python 3.11+
- `uv`
- Установленный Ollama

## Быстрый запуск

1. Запустите Ollama:

```bash
ollama serve
```

2. Загрузите хотя бы 1-2 модели (если еще не загружены):

```bash
ollama pull llama3.2
ollama pull mistral
```

3. В папке проекта запустите GUI-приложение:

```bash
uv run ollama-multi-chat
```

Альтернатива:

```bash
uv run main.py
```

## Как пользоваться GUI

1. Нажмите `Refresh Models`.
2. При необходимости откройте `Connection Settings` и укажите `host`/`timeout`.
3. Нажмите `Add Model` и подключите агентов:
- задайте имя агента;
- выберите модель из списка;
- выберите пресет системного промпта или отредактируйте текст вручную.
4. Пишите свои сообщения в нижнем поле ввода.
5. Нажмите `Старт`, чтобы модели начали общаться.
6. Нажмите `Стоп`, чтобы остановить диалог.
7. Нажмите `Сброс чата`, чтобы очистить историю.

## CLI-режим (опционально)

```bash
uv run ollama-multi-chat-cli
```

## Системные промпты

Промпты лежат в файле:

```text
system_prompts.json
```

Можно редактировать/добавлять пресеты, они появятся в окне `Add Model`.
