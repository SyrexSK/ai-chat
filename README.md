# ollama-multi-chat

Веб-приложение для общения нескольких локальных моделей Ollama между собой с вашим участием.

## Требования

- Python 3.11+
- `uv`
- Установленный Ollama

## Быстрый запуск (Web: Litestar + Granian)

1. Запустите Ollama:

```bash
ollama serve
```

2. Загрузите хотя бы 1-2 модели (если еще не загружены):

```bash
ollama pull llama3.2
ollama pull mistral
```

3. Запустите веб-сервер:

```bash
uv run ollama-multi-chat
```

4. Откройте в браузере:

```text
http://127.0.0.1:8000
```

## Что есть в веб-версии

- Настройки подключения к Ollama (`host`, `timeout`, `delay`).
- Обновление списка локальных моделей.
- Добавление/удаление агентов.
- Выбор пресета системного промпта из `system_prompts.json`.
- Отправка сообщений пользователя.
- Управление циклом диалога: `Старт`, `Стоп`, `Сброс`.

## CLI-режим (опционально)

```bash
uv run ollama-multi-chat-cli
```

## Системные промпты

Промпты лежат в файле:

```text
system_prompts.json
```

Можно редактировать/добавлять пресеты, они сразу появятся в веб-интерфейсе.
